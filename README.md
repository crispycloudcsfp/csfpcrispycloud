## Publish on GitHub Pages
1. Create/open the repository on GitHub.
2. Upload `index.html`, `README.md`, and the `assets` folder (keep the same folder structure).
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Replace the placeholder canonical URL in `index.html` with the actual GitHub Pages URL after the site is published.
